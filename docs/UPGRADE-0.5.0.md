# 升级到 0.5.0

更新前可用宿主导出聊天 JSONL。首次打开旧聊天时，插件在本地保存完整聊天快照，然后升级到 schema 8。备份失败时可在工作台重试。完成后可从「备份与恢复」导出升级前快照。

- 所有有效旧记忆保留 ID、标题、正文、故事时间、重要度、锁定及常驻标记。原待分类记忆可直接参与召回。旧关系、类别、人物和别名可在升级前快照中查阅。
- 日记保留标题和原文。旧日记摘要可在升级前快照中查阅。
- 升级前已开始的关幕保留日记与记忆审核进度。原本指向旧条目的更新建议迁为未勾选候选，只能作为新的记忆点入库。旧成长候选可在角色成长页查阅。
- 日记、记忆、成长绑定和自定义任务提示词随聊天迁移。旧近邻消息数减一得到查询深度。自定义条数上限沿用作精排候选数，旧默认值 8 更新为 10。
- 新导出的内容备份为 v4。同一聊天可导入 v2、v3 或 v4，导入会替换日记、画像和记忆点。升级前整聊天备份与内容备份分别保管。

## 回退

先导出升级后的聊天和内容以保留新增数据。切回对应旧版插件后，用宿主将升级前 JSONL 导入为聊天副本。如果只有整聊天快照，把其中 metadata 作为首行的 chat_metadata，随后按顺序写入 messages，每行一个 JSON 对象，以 UTF-8 JSONL 导入宿主。旧版插件需要与其 schema 相符的聊天。
