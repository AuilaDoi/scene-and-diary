# 从 0.3.8 升级到 0.4.0

## 升级前

1. 在宿主导出原聊天 JSONL，再从 0.3.8 插件导出 v2 内容备份。建议逐个备份仍在使用的聊天。
2. 在扩展管理器切到 `main`，更新插件并刷新宿主。
3. 打开旧聊天。插件先保存一份升级前整聊天快照，然后将 schema 6 升级为 schema 7。备份失败时旧数据保留，可从工作台重试。

## 升级后

- 日记迁为独立条目，保留正文。旧日记可在档案中补摘要，确认摘要后即可用于历史召回。
- 已有画像、事实 ID、重要度、锁定、常驻标记与故事时间随数据保留。旧偏好继续参与召回。旧习惯、承诺、事件、未区分的关系和物品／地点混合条目进入「待分类」，指定新类别后恢复召回。
- 新图谱从空图开始，旧无类型关联保存于整聊天快照。用户可主动发起全量整理并审核关系。旧版未完成的关幕草稿可在工作台继续检查，有些项目需要补摘要或重新评估。
- 在「设置」重建或新增自建 API 渠道，再按聊天绑定任务。刷新重新进入聊天，核对迁移后的日记、成长和事实。

## 选择备份

| 文件 | 用途 |
| --- | --- |
| 宿主原聊天 JSONL | 用宿主导入完整对话及导出时的元数据、消息归幕标记。 |
| 升级前整聊天备份 JSON | 在 0.4.0 工作台展开「备份与恢复」，选择「导出升级前整聊天备份」。用于恢复升级前的聊天元数据和消息。 |
| 插件内容备份 v2 或 v3 | 在同一聊天中导入，确认后替换日记、成长和事实。v3 同时恢复类型化图谱；导入 v2 会清空现图谱，旧关联可在原文件中查阅。 |

## 回退到 0.3.8

1. 在 0.4.0 中导出当前聊天和 v3 内容，另行保留升级前完整聊天备份。0.4.0 期间新增的内容可从这些文件查阅。
2. 将扩展检出切换到 [0.3.8 提交 `ca6b425`](https://github.com/AuilaDoi/scene-and-diary/tree/ca6b4252356b7678c8de965c208ad2b6c7b84c1a)，或用该提交的完整源码包替换扩展目录。刷新宿主。
3. 用宿主将升级前 JSONL 导入为聊天副本，打开并核对幕、画像、日记与记忆。只有插件快照时，将快照的 `metadata` 作为 `chat_metadata` 写入首行 JSON 对象，再按原顺序将快照 `messages` 每条写成一行 JSON。如有原聊天头，可保留其余字段。以 UTF-8 保存为 `.jsonl` 后导入副本。

0.3.8 读取 schema 6，代码降级需要配套的升级前聊天数据。继续使用 0.4.0 时，恢复扩展到 `main` 并重新打开保留的新版聊天。
