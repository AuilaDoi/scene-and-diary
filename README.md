# scene&diary 0.5.3

scene&diary 是 SillyTavern 和 TauriTavern 的单角色聊天扩展。用剧幕划分经历，关幕时整理第一人称日记和独立记忆点，在角色成长页根据日记更新画像。

## 安装与更新

在扩展安装器中使用 `https://github.com/AuilaDoi/scene-and-diary`，选择 `main`。仓库自带前端构建，刷新宿主后，从 QR（快捷回复）栏的剧幕图标打开「剧幕工作台」。QR 未启用时，从宿主扩展菜单打开。旧 RC 安装先在扩展管理器切到 `main`，再更新并刷新。

旧聊天首次打开时，插件保存升级前整聊天快照，然后迁移为 schema 8。[升级与回退](docs/UPGRADE-0.5.0.md)

## 关幕与角色成长

1. 从设置新增 OpenAI 兼容渠道，填写地址、密钥和模型。获取模型列表后可搜索选择，也可直接输入模型名。为日记和记忆提取绑定渠道并保存设置。
2. 在工作台选择「结束这一幕」。日记和记忆候选分别生成，可独立编辑、确认、跳过或重试。关幕时只新增已勾选的记忆点。
3. 两项审核完成后点「确认结束本幕」。下一条用户消息开启新幕。
4. 在「角色成长」手动选择「追踪最新动态」（默认最近 3 篇有效日记）或「全局重建」（全部有效日记）。两种模式都一次提交所选全文，审核候选后再应用。成长渠道可在首次使用时绑定。

## 聊天中的召回

插件按顺序注入当前画像、近期日记全文、全部常驻记忆和命中的普通记忆点。近期日记默认 2 篇，可单独设置。日记档案和长期记忆页都支持在条目内直接编辑。

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| 查询深度 d | 2 | 以当前用户消息结尾，向前拼接 d 条有效消息 |
| 初检数量 q | 30 | BM25 与可选向量检索融合后的候选数 |
| 精排候选数 r | 10 | 加权排序后进入阈值判断的数量 |
| 召回阈值 | 0.30 | 仅注入加权分严格高于此值的候选 |

最终分由 80% 相关度和 20% 归一化重要度组成。rerank 失败时使用检索相关度，向量服务失败时使用 BM25。将 q 或 r 设为零可关闭普通召回。常驻记忆始终独立注入。各阶段数量和失败原因见诊断。

## 任务提示词

在设置的任务标签页中编辑系统提示词与任务描述，并预览背景参考、内容素材和固定的格式规定。每次生成只发送这五个模块。渠道通过普通文本返回带任务标签的 JSON。[宿主与 API 兼容范围](COMPATIBILITY.md)

## 保存与备份

工作台的「备份与恢复」可导出内容、导入同一聊天的内容备份，或导出升级前整聊天备份。宿主报告保存失败时，当前内容仍可编辑，选择「重试保存」或先导出。不同备份的用途与恢复步骤见升级说明。[升级与回退](docs/UPGRADE-0.5.0.md)
