# scene&diary 0.4.0

scene&diary 是 SillyTavern 和 TauriTavern 的单角色聊天扩展。用剧幕划分经历，关幕时整理第一人称日记、当前角色画像和可长期使用的客观事实。

## 安装与更新

在扩展安装器中使用 `https://github.com/AuilaDoi/scene-and-diary`，选择 `main`。仓库自带前端构建，刷新宿主后，从发送区旁的剧幕图标打开「剧幕工作台」。旧 RC 安装先在扩展管理器切到 `main`，再更新并刷新。

从 0.3.8 升级时，先导出原聊天和插件内容备份。升级后首次打开旧聊天会进行备份和迁移，再为整理任务绑定自建 API 渠道。[升级与回退](docs/UPGRADE-0.4.0.md)

## 第一次关幕

1. 在「设置 → API 渠道」新增 OpenAI 兼容渠道。填写地址、密钥和模型，可先获取模型列表并测试。
2. 在同一面板的「任务分派」为日记、成长和事实提取绑定渠道，保存聊天设置。如需自动补日记摘要或整理图谱，再绑定对应任务。多个任务可选同一渠道。
3. 在工作台点「结束这一幕」。日记和事实提取分别生成。确认日记正文和单篇摘要后，插件才评估角色成长。
4. 编辑、确认或跳过各项。生成失败可单独重试，已处理的其他项保留。日记跳过时一并跳过成长评估。三项处理完毕后点「确认结束本幕」，下一条玩家消息开启新幕。

## 整理长期内容

| 页面 | 可以做什么 |
| --- | --- |
| 角色成长 | 编辑当前画像，或根据全部有效日记重整。重整稿可对照现画像，审核后再应用。 |
| 日记档案 | 按单篇搜索、阅读和编辑正文与摘要。正文改变后可重新核对摘要，也可批量为旧日记补摘要。 |
| 长期记忆 | 管理偏好、NPC 关系、重要物品和地点。审核新增、重复、补充与状态变化建议。可编辑、锁定、常驻或删除。图谱支持查看和编辑有方向的关系，审核全量或增量整理结果。 |

当前幕对话留在正常聊天上下文中。插件依次注入当前画像、近期日记全文、相关历史日记摘要和召回的事实。近期日记默认两篇，历史摘要默认约 600 token，长期事实默认约 1,200 token，各项可在设置中单独调整。语义检索可选接入 Embedding 和 rerank。「诊断」显示耗时、入选条目及额度跳过原因。[宿主与 API 兼容范围](COMPATIBILITY.md)

## 保存与备份

工作台的「备份与恢复」可导出内容、导入同一聊天的内容备份，或导出升级前整聊天备份。宿主报告保存失败时，当前内容仍可编辑，选择「重试保存」或先导出。不同备份的用途与恢复步骤见升级说明。[升级与回退](docs/UPGRADE-0.4.0.md)
